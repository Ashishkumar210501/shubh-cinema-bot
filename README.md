# 🎬 Shubh Cinema Admin Bot (@ShubhCinema_bot)

यह **Shubh Cinema** ऐप के लिए एक ऑटोमेटेड टेलीग्राम एडमिन बॉट है, जिसे पायथन (`pyTelegramBotAPI`) और Google Apps Script के साथ डिप्लॉय किया गया है। यह बॉट सीधे Google Sheet डेटाबेस के साथ इंटरैक्ट करता है।

---

## 🚀 फीचर्स (Features)
* **मल्टी-टैब डेटा मैनेजमेंट:** Google Sheet के सभी 6+ टैब (`Recent`, `Movies`, `Series`, `TV_Shows`, `Old_Is_Gold`, `Adult`, `Users_Lock`) को मैनेज करने की क्षमता।
* **क्विक एडमिन कंट्रोल्स:** टेलीग्राम से सीधे फिल्में, सीरीज और शो जोड़ने के लिए आसान कीबोर्ड बटन्स।
* **क्लाउड होस्टिंग:** `bot-hosting.net` पर 24/7 रनिंग।

---

## 🛠️ टेक स्टैक (Tech Stack)
* **Language:** Python 3.10+
* **Library:** `pyTelegramBotAPI`, `requests`
* **Database:** Google Sheets & Google Apps Script Web App
* **Hosting:** bot-hosting.net & GitHub

---

## ⚙️ सेटअप कैसे करें (Setup)
1. रिपॉजिटरी को क्लोन या अपलोड करें।
2. `requirements.txt` से डिपेंडेंसी इंस्टॉल करें।
3. `main.py` में अपना `BOT_TOKEN` और `GAS_URL` सेट करें।
4. बॉट को होस्टिंग सर्वर पर रन करें!
